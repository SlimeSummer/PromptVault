# 阶段 2.5e：词条批量删除

> 完成日期：2026-11-04

## 目标

在全局词库的分页表格中勾选多条词条，一键批量删除。

## 实现

- 后端 `TagService.batchDelete(ids)`：逐条做引用检查（被预设/词组/编辑区引用的词条不允许删），任一被引用则返回具体阻塞原因；`IdsRequest` 用 JSON body 包裹 `{ ids: [1,2,3] }`，契约稳定。
- `TagController` 新增 `POST /api/tags/batch-delete`。
- 前端词库页：
  - 表头加全选复选框，每行独立勾选框。
  - 顶部加红色"批量删除（N）"按钮，未选中时禁用。
  - 点删除弹确认框，成功后 toast 提示 + 自动刷新列表与统计。

## 验证

- `clean compile` BUILD SUCCESS（28 文件）；`npm run build` 1627 modules PASS。
- 接口：79 条删 3 → 76 条；空 ids → `code=1 未选择任何词条`。
- 浏览器：全选 20 条删除成功，分页器自动刷新，按钮回退到禁用状态。
- 用户数据最终 56 条，无额外删除；8081 已释放。
