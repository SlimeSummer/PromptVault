# 0003. 预设是角色基线，不是完整提示词

- 状态：已接受
- 日期：2026-11-03

## 背景

用户希望 LoRA 的预设像"库方法"一样可复用：调用预设得到稳定的角色身份与穿搭，再自己补动作、场景、表情。
如果把动作/场景也写进预设，预设就会退化成一条完整提示词，换个场景就不能复用。

## 决策

预设（`preset`）只保存**角色基线**：

- 触发词 / 身份特征；
- 穿搭方案；
- 画风锚点（质量词、风格词）；
- 该 LoRA 特有的负向词。

动作、场景、表情、细节放到 `tag_group`（词组）或 `workspace`（编辑区）里组装。

## 后果

- 同一角色可以在不同场景复用同一预设，符合"调库 + 自定义逻辑"的使用方式。
- 组装时需要编辑区把预设展开，再叠加词组/标签；`workspace_item` 采用"引用 + 动态展开"而不是快照。
- 用户需要理解"预设 ≠ 完整提示词"这一层概念，界面上用文案明确说明。

## 备选方案

- **预设保存完整提示词**：复制即可用，但几乎不可复用，改场景就要重新建预设。
- **预设只存触发词**：最轻，但穿搭、画风这些真正耗时的经验又回到记事本里。
