# 0001. 交付形态：本地 Web 应用

- 状态：已接受
- 日期：2026-11-03

## 背景

PromptVault 是单人使用的提示词经验库，数据是长期积累的个人资产。需求同时包含：
浏览器里好用的检索/编辑界面、可靠的数据持久化、未来可能与 ComfyUI 的 PNG 元数据对接。

## 决策

采用**本地 Web 应用**：

- 后端：Java 17 + Spring Boot 3.3.5 + MyBatis + SQLite 单文件；
- 前端：Vue 3 + Vite + Element Plus，浏览器访问；
- 开发期后端 8080、前端 5173（Vite 代理 `/api`），生产构建把前端产物打进 jar。

## 后果

- 数据落在 `data/promptvault.db` 一个文件里，备份/迁移只需复制目录。
- 完全离线可用，不依赖云服务，隐私成本最低。
- 开发时需要同时启动两个进程；生产环境只启动一个 jar。
- 用户需要安装 JDK 17+ 与 Node 18+（仅开发时）。

## 备选方案

- **Electron / Tauri 桌面应用**：安装包更"像软件"，但前端打包链更重，且后端能力仍要单独选型，收益不明显。
- **纯浏览器 + localStorage / IndexedDB**：零后端，但数据易丢失、难备份，也不适合后续做导入解析。
- **云端服务**：可跨设备，但涉及部署、账号、隐私，超出个人工具的范围。
