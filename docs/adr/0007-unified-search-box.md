# 0007. 搜索框统一为「补全 + 搜索按钮」组件

- 状态：已接受
- 日期：2026-11-04

## 背景

词库、词组库、LoRA 列表原本各自实现搜索：有的只有输入框、有的有补全、有的有按钮，交互不一致。用户明确提出一条长期原则：**凡是有搜索框的地方都要有搜索补全，并且旁边要有搜索按钮**。

## 决策

抽出 `web/src/components/SearchBox.vue`：

- 基于 `el-autocomplete`，`suggest(keyword)` 由调用方传入，组件不关心数据来源；
- `suggest` 可返回字符串数组或 `{ value, sub }` 对象数组，统一归一化；
- 回车 / 选中项 / 清除 / 点击按钮都触发 `search` 事件；
- 按钮默认显示，可关闭（少数场景只需要补全）。

后端补全接口统一命名与参数：`GET .../suggest?keyword=&limit=`，按"前缀优先、其余包含"排序，`limit` 服务端夹取。

## 后果

- 新增页面只要引组件 + 传一个 suggest 函数即可，交互风格自动一致；
- 搜索触发点收敛为 `search` 事件，页面只负责一次 `load()`；
- 后端需要为每类实体提供 suggest 接口，少量重复 SQL 可接受。

## 备选方案

- 每个页面继续手写 autocomplete + button：重复代码多，风格容易漂移，否决。
- 只做补全不做按钮：不符合用户明确要求，也失去"确认搜索"的显式动作，否决。
